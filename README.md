# Садовая мастерская (Garden Workshop) — Mobile-First Merge Puzzle

**Официальная версия игры:** `0.1.0` (Release Candidate)  
**Дата сборки:** 18 августа 2026 г.  
**Целевая платформа:** Яндекс Игры (Yandex Games Web SDK v2)  
**Поддерживаемые экраны:** Мобильные устройства (портретный режим 360×640, 390×844) и десктопы (768×1024, 1366×768, 1920×1080)  
**Языки:** Русский (RU — основной), Английский (EN — архитектурно подготовлен)

---

## 🌿 О проекте

«Садовая мастерская» — это оригинальная 2D merge-головоломка в портретной ориентации, созданная на движке Phaser 3 с использованием TypeScript. Игрок объединяет одинаковые садовые предметы на сетке 6x6, выращивая всё более редкие растения и элементы декора (от обычного семечка до цветущих кустов и декоративного пруда), выполняет заказы посетителей и восстанавливает заброшенный парк.

---

## 🛠 Технический стек и архитектура

- **Ядро:** Phaser 3 (Canvas/WebGL с автоматическим масштабированием `Scale.FIT` и центрированием `CENTER_BOTH`)
- **Язык:** TypeScript (Strict Mode, 100% покрытие типов)
- **Сборщик:** Vite 6
- **Звук:** Процедурный синтез Web Audio API (без тяжелых внешних аудио-ассетов, со строгим соответствием Autoplay Policy — разблокировка звука строго по первому пользовательскому жесту)
- **Графика:** Высокопроизводительные векторные Canvas-текстуры с частицами и мягкими градиентами
- **Интеграция:** Адаптерная архитектура `IPlatformAdapter`:
  - `MockPlatformAdapter` — для автономной разработки и локального QA
  - `YandexPlatformAdapter` — для продакшн-среды Яндекс Игр (Player API, Cloud Save, Ad SDK, LoadingAPI, GameplayAPI)

## 💰 Монетизационные сценарии

1. **Rewarded Video (Реклама с вознаграждением):**
   - Доступна добровольно при переполнении доски («Удалить младшее растение»).
   - Вознаграждение начисляется **строго** по callback успешного завершения просмотра.
   - Нет блокировки ячеек или навязанных покупок — все 36 ячеек доступны бесплатно со старта.
2. **Interstitial (Межстраничная реклама):**
   - Показывается исключительно в безопасных логических паузах (после сдачи каждых 3 заказов).
   - Никогда не вызывается во время перетаскивания (drag-and-drop), в меню обучения или до начала игрового процесса.
   - Во время показа рекламы игра вызывает `gameplayStop()`, заглушая звуки и останавливая таймеры, а после закрытия вызывает `gameplayStart()`.

## 📦 Сборка Production-архива для Яндекс Игр

### 1. Компиляция и сборка
```bash
npm run build
```

### 2. Создание ZIP-архива
Архив создается **из содержимого папки `dist`** (в корне архива должен находиться `index.html`):

```bash
# В Linux / macOS:
cd dist && zip -r ../garden-workshop-0.1.0.zip . && cd ..

# В Windows PowerShell:
Compress-Archive -Path dist/* -DestinationPath garden-workshop-0.1.0.zip -Force
```

**Проверка структуры архива:**
```text
garden-workshop-0.1.0.zip
├── index.html
├── assets/
│   ├── index-[hash].js
│   └── index-[hash].css
└── ...
```

## 📝 Известные особенности и ограничения

- В локальной среде разработки без `YaGames` SDK игра автоматически переключается на `MockPlatformAdapter` с эмуляцией сохранения в `localStorage`.
- В среде Яндекс Игр при отсутствии авторизации игрока (гостевой режим) игра сохраняет прогресс в `localStorage` и не блокирует запуск.
- При сворачивании вкладки или переключении на другое приложение срабатывает `SaveManager.flush()` для гарантированного сохранения состояния.
