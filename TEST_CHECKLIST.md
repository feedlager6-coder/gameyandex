# Чек-лист тестирования (QA Test Checklist)

Проверка соответствия требованиям качества и правилам публикации **Яндекс Игр**.

## 1. Респонсивность и экраны (Responsive UI)
- [ ] **360x640** (Бюджетные Android смартфоны): Canvas масштабируется без обрезки UI, шрифты читаемы, кнопки и ячейки попадают в область нажатия.
- [ ] **390x844** (iPhone / современные смартфоны): Идеальное заполнение по высоте без деформации пропорций.
- [ ] **768x1024** (Планшеты iPad / Android): Центрирование холста `CENTER_BOTH`, фон вокруг холста аккуратно окрашен в цвет темы.
- [ ] **1366x768 / 1920x1080** (Десктоп): Холст центрирован, отсутствие системного скроллбара, перетаскивание мышью работает плавно.

## 2. Управление (Touch & Mouse)
- [ ] Перетаскивание предметов пальцем на сенсорном экране (drag-and-drop) без задержек и залипаний.
- [ ] Перетаскивание предметов мышью на десктопе.
- [ ] Предотвращение нативного скролла страницы при перетаскивании предметов (`touch-action: none`).
- [ ] Возврат предмета в исходную ячейку при отпускании в недопустимой зоне.

## 3. Игровые механики (Gameplay Core)
- [ ] Поле 6x6 (все 36 клеток доступны со старта).
- [ ] Клик по «Корзине семян» спавнит семечко 1 уровня (или росток с шансом при открытии ур. 3+).
- [ ] Объединение двух одинаковых предметов уровня $N$ создает предмет уровня $N+1$ с анимацией звезд и звуковым сигналом.
- [ ] Перетаскивание разнородных предметов меняет их местами на доске.
- [ ] Прогресс уровней: открытие новых предметов от 1 (Семечко) до 8 (Декоративный пруд) с тост-уведомлением.
- [ ] 3 активных заказа обновляются при сдаче готового растения, начисляются монеты.
- [ ] Экран сада: 4 участка восстанавливаются за заработанные монеты с визуальным апгрейдом (ур. 0..3).

## 4. Сохранения и Offline-Safe поведение (Saves)
- [ ] Перезагрузка страницы (`F5`) восстанавливает точное положение всех предметов на сетке 6x6.
- [ ] Сохранение баланса монет, открытого максимального уровня и прогресса сада.
- [ ] Автоматический flush в облако при скрытии вкладки (`visibilitychange`) и дебаунс 1.5 сек.
- [ ] Возможность сбросить прогресс в меню настроек.

## 5. Звук и Вибрация (Audio Policy)
- [ ] Нет ошибок `AudioContext was not allowed to start` при первичной загрузке страницы.
- [ ] Звуковой контекст корректно активируется по первому нажатию пользователя на экран.
- [ ] Переключатель звука в меню и на паузе выключает/включает звуки.
- [ ] Переключатель вибрации работает на поддерживаемых мобильных устройствах.

## 6. Интеграция с Яндекс Играми (Yandex Games SDK)
- [ ] **Game Ready**: Метод `platform.loadingReady()` (`LoadingAPI.ready()`) вызывается строго после отрисовки интерактивного главного меню.
- [ ] **Реклама с вознаграждением (Rewarded)**: При переполнении доски кнопка «Удалить слабое семечко (Реклама)» вызывает `showRewarded()`; награда выдается **строго** после успешного завершения просмотра.
- [ ] **Межстраничная реклама (Interstitial)**: Показывается в логической паузе (каждые 3 выполненных заказа) с безопасным возобновлением геймплея.
- [ ] **Фоновая пауза**: Во время рекламы вызывается `gameplayStop()`, после окончания — `gameplayStart()`.
- [ ] **Гостевой вход**: Игра работает моментально без принудительной авторизации или всплывающих окон входа.
