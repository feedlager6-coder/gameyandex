# Чек-лист тестирования (QA Test Checklist) — Садовая мастерская v0.1.0

Комплексный чек-лист соответствия техническим требованиям и правилам модерации **Яндекс Игр** перед отправкой на релиз.

---

## 📱 1. Запуск, устройства и респонсивный интерфейс (Responsive UI)

- [ ] **360×640 (Бюджетные смартфоны Android):**
  - Холст корректно масштабируется (`Scale.FIT`), нет размытия текста и обрезки элементов.
  - Сенсорные области кнопок соответствуют минимальным размерам для удобного нажатия.
  - Доска 6x6, верхний HUD (монеты, пауза, сад) и нижний блок (заказы и корзина) не перекрывают друг друга.
- [ ] **390×844 (iPhone 12/13/14/15/16, современные Android):**
  - Идеальное заполнение рабочей зоны экрана по вертикали с безопасными отступами.
- [ ] **768×1024 (Планшеты iPad / Android):**
  - Автоматическое центрирование холста (`CENTER_BOTH`), приятный фоновый цвет за пределами игровой области.
- [ ] **1366×768 и 1920×1080 (Десктопные мониторы):**
  - Холст центрирован, отсутствие нежелательного горизонтального и вертикального скроллбаров страницы.
  - Управление мышью (drag-and-drop) плавное и без лагов.
- [ ] **Браузерная кроссплатформенность:**
  - Chrome Android, Яндекс Браузер Android, Chrome Desktop, Яндекс Браузер Desktop, Safari (iOS / macOS), Firefox.
- [ ] **Предотвращение скролла:** `touch-action: none` блокирует нативное перетаскивание страницы во время игры.
- [ ] **Интуитивность интерфейса:** Игрок без подсказок сразу видит корзину для спавна, сетку 6x6, активные заказы, монеты и кнопку перехода в сад.

## 🎮 2. Игровой цикл и механики слияния (Core Merge Loop)

- [ ] **Старт новой игры:** Корректно открывается интерактивное стартовое меню с кнопкой «Играть».
- [ ] **Обучение (Tutorial):** Первое прохождение сопровождается кратким понятным диалоговым окном; повторный показ не навязывается при перезапуске.
- [ ] **Линейка предметов (8 уровней):**
  - Ур. 1: Семечко (Seed)
  - Ур. 2: Росток (Sprout)
  - Ур. 3: Саженец (Seedling)
  - Ур. 4: Горшечный цветок (Potted Flower)
  - Ур. 5: Цветущий куст (Flowering Bush)
  - Ур. 6: Плодовое дерево (Fruit Tree)
  - Ур. 7: Декоративный фонтан (Garden Fountain)
  - Ур. 8: Японский пруд с карпами (Japanese Pond)
- [ ] **Механика слияния (Merge):**
  - Перетаскивание двух одинаковых предметов уровня $N$ создает предмет уровня $N+1$ со вспышкой частиц, анимацией масштабирования и звуковым аккордом.
  - Слияние максимального 8 уровня блокируется (предмет максимального развития).
- [ ] **Отмена и перестановка:**
  - Перенос предмета в пустую ячейку перемещает его.
  - Перенос на ячейку с предметом другого уровня безопасно меняет их местами на доске (swap).
  - Отпускание предмета за пределами сетки возвращает его в исходную ячейку с плавной анимацией возврата.
- [ ] **Генерация заказов:**
  - В HUD одновременно доступны 3 заказа от посетителей.
  - Заказы генерируются строго с уровнем не выше `unlockedMaxLevel` (все заказы выполнимы!).
  - При сдаче заказа готовый предмет удаляется с доски, начисляются монеты, запускается анимация салюта монет и генерируется новый заказ.
- [ ] **Восстановление сада (Garden Scene):**
  - 4 участка сада (Клумбы, Фонтанная аллея, Плодовый сад, Зона отдыха) имеют 3 уровня улучшения каждый.
  - При покупке апгрейда монеты списываются, визуальная сцена обновляется, состояние фиксируется.
- [ ] **Переполнение доски и Game-Over / Rewarded Rescue:**
  - Ситуация переполнения определяется строго: когда все 36 ячеек заняты И нет ни одной пары для слияния.
  - Игроку предлагается спасение: удалить одно случайное слабое растение (ур. 1-2) за просмотр рекламы, либо очистить поле через модальное окно.

## 💾 3. Сохранения, отказоустойчивость и миграции (Persistence)

- [ ] **Обновление страницы (F5):** Доска, монеты, открытые уровни и апгрейды сада восстанавливаются 1:1.
- [ ] **Закрытие вкладки:** При закрытии окна или переходе на другой URL срабатывает событие `visibilitychange` -> моментальный `flush` в `localStorage` и в облако Яндекса.
- [ ] **Быстрые серии действий:** Три быстрых действия подряд (перемещение, слияние, сдача заказа) не приводят к рассинхронизации или дублированию предметов.
- [ ] **Миграция версий (`schemaVersion`):** При изменении структуры сохранения дефолтные значения подставляются без краша игры.
- [ ] **Отказоустойчивость Cloud Save:** При сбое сети или ошибках Яндекс Player API игра бесшовно продолжает работать на локальном хранилище без потери данных.

## 🔊 4. Звуковая система и Политика автовоспроизведения (Audio Policy)

- [ ] **Autoplay Policy:** Никаких звуков и ошибок в консоли браузера до первого клика / тапа игрока.
- [ ] **Разблокировка Web Audio:** При первом взаимодействии с экраном синтезатор мягко инициализируется.
- [ ] **Процедурные эффекты:**
  - Клик по кнопке / выбор
  - Спавн семечка
  - Звук слияния с гармоническим повышением тона
  - Начисление монет и выполнение заказа
  - Фанфары открытия нового предмета
- [ ] **Настройки звука:** Переключатели «Звук» и «Вибрация» мгновенно отключают/включают эффекты и сохраняют выбор в профиле.

## 🌐 5. Интеграция с платформой Яндекс Игры (Yandex Games SDK)

- [ ] **Инициализация:** Скрипт `https://yandex.ru/games/sdk/v2` подключен асинхронно в `index.html`.
- [ ] **Loading API (`loadingReady`):** Вызывается ровно один раз строго в момент готовности интерактивного главного меню.
- [ ] **Game Ready:** Игра становится полностью интерактивной в течение первых секунд (норматив Яндекса < 90 сек).
- [ ] **Player API (Облачные сохранения):**
  - Поддержка авторизованных пользователей через `player.setData()` / `player.getData()`.
  - Поддержка неавторизованных пользователей (гостевой режим) без блокирующих окон.
- [ ] **Реклама с вознаграждением (Rewarded Video):**
  - Вызывается только по явному клику пользователя на кнопку с наградой.
  - Награда начисляется **строго** внутри callback'а `onRewarded`.
  - Закрытие рекламы без досмотра не начисляет награду.
- [ ] **Межстраничная реклама (Interstitial):**
  - Показывается исключительно в паузах (после сдачи 3 заказов).
  - Защита от спама: минимальный интервал между показами (cooldown).
  - Не блокирует ввод и не ломает модальные окна.
- [ ] **Фокусировка и Gameplay API:**
  - При старте показа рекламы вызывается `gameplayStop()` (звуки глушатся, игра на паузе).
  - При завершении рекламы вызывается `gameplayStart()` (звуки восстанавливаются).
